# Thai Beginner Learning Record 001: Greetings, Thanks, and Names

Date: 2026-08-17
Learner level: Complete beginner

Today focused on basic greetings, thanks, self-introduction, and asking names.
This is a first review note from practice, not a mastery checklist.

## Session Focus

| Thai | Transliteration | Meaning / Use |
| --- | --- | --- |
| สวัสดี | sà-wàt-dii | hello / greeting |
| ครับ | khráp | polite ending used by a male speaker |
| ค่ะ | khâ | polite ending used by a female speaker |
| ขอบคุณ | khàawp-khun | thank you |
| ใช่ | châi | yes |
| ไม่ใช่ | mâi châi | no / not |
| ลาก่อน | laa-gàawn | goodbye |
| ผมชื่อ ... ครับ | phǒm chʉ̂ʉ ... khráp | my name is ... / male speaker |
| คุณชื่ออะไร | khun chʉ̂ʉ a-rai | what is your name? |

## Practiced In This Session

- Greeting someone: สวัสดี
- Adding a polite ending: ครับ for a male speaker, ค่ะ for a female speaker
- Saying thank you: ขอบคุณ
- Answering yes: ใช่
- Answering no / not: ไม่ใช่
- Saying goodbye: ลาก่อน
- Introducing yourself as a male speaker: ผมชื่อ Lucas ครับ
- Asking another person's name: คุณชื่ออะไร

## Review Notes

- Keep the Thai script and transliteration together while reviewing.
- Practice the polite endings with the speaker's gender in mind.
- Use ผมชื่อ Lucas ครับ only as the practiced male self-introduction from this session.
- Review คุณชื่ออะไร as the basic way practiced today to ask someone's name.
