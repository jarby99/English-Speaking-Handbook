## 拉丁拼音拆分

### 我不明白 | ไม่เข้าใจ | mâi khâo jai

- `mâi` = 不
- `khâo jai` = 明白 / 理解，固定短语

### 很高兴认识你 | ยินดีที่ได้รู้จัก | yin-dii thîi dâai rúu jàk

- `yin-dii` = 高兴
- `thîi` = 连接词
- `dâai` = 得以 / 能够
- `rúu jàk` = 认识某个人

### 你来自哪里？ | คุณมาจากไหน | khun maa jàak nǎi?

- `khun` = 你
- `maa` = 来
- `jàak` = 从 / 来自
- `nǎi` = 哪里

### 我来自中国。 | ผมมาจากประเทศจีนครับ | phǒm maa jàak bprà-thêet jiin khráp

- `phǒm` = 我（男性用）
- `maa jàak` = 来自
- `bprà-thêet` = 国家
- `jiin` = 中国
- `khráp` = 男性礼貌结尾

### 幸福 | ความสุข | khwaam suk

- `khwaam suk` = 幸福

### 有幸福 / 幸福的状态 | มีความสุข | mii khwaam suk

- `mii` = 有
- `khwaam suk` = 幸福

### 幸福地 | อย่างมีความสุข | yàang mii khwaam suk

- `yàang` = 以……方式 / ……地
- `mii` = 有
- `khwaam suk` = 幸福
- 整体表达做某事时是幸福 / 开心的方式。

### 哥哥 / 年长男性兄长 | พี่ชาย | phîi chaai

- `phîi` = 年长的哥哥 / 姐姐或年长者
- `chaai` = 男性

### 妹妹 | น้องสาว | nóng sǎao

- `nóng` = 年幼的兄弟姐妹 / 年幼者
- `sǎao` = 女性 / 女孩
- `nóng sǎao` = 妹妹

### 中国 | จีน | jiin

- `jiin` = 中国

### 你来自哪里？（男性礼貌问法） | คุณมาจากไหนครับ | khun maa jàak nǎi khráp

- `khun` = 你
- `maa jàak` = 来自
- `nǎi` = 哪里
- `khráp` = 男性礼貌结尾

### 我来自中国。（简洁男性回答） | ผมมาจากจีนครับ | phǒm maa jàak jiin khráp

- `phǒm` = 我（男性用）
- `maa jàak` = 来自
- `jiin` = 中国
- `khráp` = 男性礼貌结尾

### 你的声音真好听 | เสียงคุณเพราะมากครับ | sǐang khun phráw mâak khráp

- `sǐang` = 声音
- `khun` = 你
- `phráw` = 好听 / 悦耳
- `mâak` = 非常 / 很
- `khráp` = 男性礼貌结尾
