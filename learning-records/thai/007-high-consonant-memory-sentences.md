注意：ฃ 是旧字，现在日常基本不用，但字母表里仍然需要认识。

## 高辅音基础发音规则

先记这份零基础简化规则。真正读音还要结合具体单词反复听。

### 1. 高辅音没有声调符号

- 高辅音 + 短元音 + 没有结尾辅音：读第 2 调，低调，拉丁拼音常写 à。本篇例子：สบายดี 里的 สะ，写成 sà。
- 高辅音 + 短元音 + 鼻音结尾 m / n / ng：读第 5 调，升调，拉丁拼音常写 ǎ。本篇例子：ฉัน chǎn、ผม phǒm、ฝน fǒn、ถุง thǔng。
- 高辅音 + 长元音，或高辅音 + 长元音 + 鼻音结尾：多读第 5 调，升调，拉丁拼音常写 ǎ。本篇例子：ฐาน thǎan、ศาลา sǎa-laa。
- 高辅音 + p / t / k 这类收尾音：属于死音节，读第 2 调，低调，拉丁拼音常写 à。本篇例子：ขวด khùat。

记忆句：高辅音没有声调符号时，活音节多读升调，死音节多读低调。

### 2. 高辅音加声调符号

- ่，泰语名字是 ไม้เอก。高辅音加这个符号，读第 2 调：低调，拉丁拼音常写 à。本篇例子：ไข่，khài。
- ้，泰语名字是 ไม้โท。高辅音加这个符号，读第 3 调：降调，拉丁拼音常写 â。本篇例子：ห้า，hâa。

本篇先重点记这两个：่ 让高辅音读低调，้ 让高辅音读降调。

### 3. 看 ฉัน 的规则

ฉัน 上面的 ั 不是声调符号，它是短元音 a。

ฉัน | chǎn | 我

拆开看：ฉ 是高辅音，ั 是短 a，น 是 n 结尾。n 结尾让它成为活音节，所以没有声调符号时读第 5 调：升调。

### 1. 高辅音 ข

中文意思：鸡蛋
泰语：ไข่
拉丁拼音读音：khài
简单日常泰语例句：ผมกินไข่ครับ
> 例句拆解：ผม (phǒm)＝我（男性用）｜กิน (gin)＝吃｜ไข่ (khài)＝鸡蛋｜ครับ (khráp)＝男性礼貌结尾
> 发音规则提示：按括号里的拉丁拼音声调标记读：à＝低调，â＝降调，á＝高调，ǎ＝升调。 句末 ครับ | khráp 是男性礼貌结尾，末尾轻轻收在 p。 ไข่ 里的 ่ 是声调符号ไม้เอก；高辅音 ข + ่ 读低调 khài。

中文句意：我吃鸡蛋。

### 2. 高辅音 ฃ

中文意思：旧字 ฃ，只用于认识字母；瓶子的现代常用写法是 ขวด
泰语：ขวด
拉丁拼音读音：khùat
简单日常泰语例句：ขวดอยู่ที่นี่
> 例句拆解：ขวด (khùat)＝瓶子｜อยู่ (yùu)＝在｜ที่นี่ (thîi-nîi)＝这里
> 发音规则提示：按括号里的拉丁拼音声调标记读：à＝低调，â＝降调，á＝高调，ǎ＝升调。 ขวด 没有声调符号，末尾 ด 是 t 收尾，属于死音节，所以读第 2 调低调 khùat，末尾轻轻收住。

中文句意：瓶子在这里。

### 3. 高辅音 ฉ

中文意思：我
泰语：ฉัน
拉丁拼音读音：chǎn
简单日常泰语例句：ฉันสบายดี
> 例句拆解：ฉัน (chǎn)＝我｜สบายดี (sà-baai dii)＝很好 / 状态好
> 发音规则提示：按括号里的拉丁拼音声调标记读：à＝低调，â＝降调，á＝高调，ǎ＝升调。 ฉัน 上面的 ั 是短元音 a，不是声调符号；ฉ 是高辅音，น 是 n 鼻音结尾，所以是“高辅音 + 短元音 + 鼻音结尾”，读第 5 调升调 chǎn。 สบายดี 里的 สะ 是“高辅音 + 短元音 + 没有结尾辅音”，读第 2 调低调 sà。

中文句意：我很好。

### 4. 高辅音 ฐ

中文意思：基础
泰语：ฐาน
拉丁拼音读音：thǎan
简单日常泰语例句：ฐานนี้ดี
> 例句拆解：ฐาน (thǎan)＝基础｜นี้ (níi)＝这个｜ดี (dii)＝好
> 发音规则提示：按括号里的拉丁拼音声调标记读：à＝低调，â＝降调，á＝高调，ǎ＝升调。 ฐาน 没有声调符号；ฐ 是高辅音，า 是长元音 aa，น 是 n 鼻音结尾，属于活音节，所以读第 5 调升调 thǎan。

中文句意：这个基础很好。

### 5. 高辅音 ถ

中文意思：袋子
泰语：ถุง
拉丁拼音读音：thǔng
简单日常泰语例句：ถุงนี้ของผม
> 例句拆解：ถุง (thǔng)＝袋子｜นี้ (níi)＝这个｜ของ (khǎawng)＝属于 / 的｜ผม (phǒm)＝我（男性用）
> 发音规则提示：按括号里的拉丁拼音声调标记读：à＝低调，â＝降调，á＝高调，ǎ＝升调。 ถุง 没有声调符号；ถ 是高辅音，ง 是 ng 鼻音结尾，所以是“高辅音 + 短元音 + 鼻音结尾”，读第 5 调升调 thǔng。 ของ 也是高辅音 ข + 鼻音结尾 ng，读升调 khǎawng。 ผม 是高辅音 ผ + 短元音 + m 鼻音结尾，读升调 phǒm。

中文句意：这个袋子是我的。

### 6. 高辅音 ผ

中文意思：我（男性用）
泰语：ผม
拉丁拼音读音：phǒm
简单日常泰语例句：ผมชื่อ Lucas ครับ
> 例句拆解：ผม (phǒm)＝我（男性用）｜ชื่อ (chʉ̂ʉ)＝名字 / 叫｜Lucas (Lucas)＝Lucas｜ครับ (khráp)＝男性礼貌结尾
> 发音规则提示：按括号里的拉丁拼音声调标记读：à＝低调，â＝降调，á＝高调，ǎ＝升调。 ผม 没有声调符号；ผ 是高辅音，ม 是 m 鼻音结尾，所以是“高辅音 + 短元音 + 鼻音结尾”，读第 5 调升调 phǒm。 句末 ครับ | khráp 是男性礼貌结尾，末尾轻轻收在 p。

中文句意：我叫 Lucas。

### 9. 高辅音 ษ

中文意思：隐士

### 11. 高辅音 ห
