# Thai Beginner Learning Record 007: 泰语辅音、元音和高辅音复习

日期：2026-09-06
学习者水平：零基础

本页用于把截图里的泰语 44 个辅音重新整理成可复习的卡片，并保留高辅音记忆句。这里是记忆材料，不是掌握清单。

## 本次重点

复习顺序：中文意思 | 泰语 | 拉丁拼音读音。

先看三件事：

1. 辅音类别：中辅音、高辅音、低辅音。
2. 声调判断：辅音类别 + 声调符号 + 活音节 / 死音节。
3. 元音位置：泰语元音可能写在辅音前、后、上、下；下面用 `-` 表示辅音放置的位置。

## 元音归纳

下面先按零基础常见读法整理。`-` 只是位置标记，表示辅音放在这里；它不是泰语字母本身。

### 1. 单元音

- 短 a：-ะ，读 a；常见标注如 sà 里的 a。
- 长 aa：-า，读 aa；例：ลา | laa。
- 短 i：-ิ，读 i。
- 长 ii：-ี，读 ii；例：ดี | dii。
- 短 ue：-ึ，读 ue。
- 长 uue：-ือ，读 uue；例：ชื่อ | chʉ̂ʉ。
- 短 u：-ุ，读 u。
- 长 uu：-ู，读 uu。
- 短 e：เ-ะ，读 e。
- 长 ee：เ-，读 ee。
- 短 ae：แ-ะ，读 ae。
- 长 aae：แ-，读 aae。
- 短 o：โ-ะ，读 o。
- 长 oo：โ-，读 oo。
- 短 aw：เ-าะ，读 aw。
- 长 aaw：-อ，读 aaw；例：ขอ | khǎaw。
- 短 oe：เ-อะ，读 oe。
- 长 ooe：เ-อ，读 ooe。

### 2. 复合元音

- ia：เ-ีย，读 ia。
- uuea：เ-ือ，读 uuea。
- ua：-ัว，读 ua。
- ai：ไ- / ใ-，读 ai；例：ใช่ | châi。
- ao：เ-า，读 ao。
- am：-ำ，读 am。

## 高辅音基础发音规则

先记这份零基础简化规则。真正读音还要结合具体单词反复听。

### 1. 高辅音没有声调符号

- 高辅音 + 短元音 + 没有结尾辅音：读第 2 调，低调，拉丁拼音常写 à。本篇例子：สบายดี 里的 สะ，写成 sà。
- 高辅音 + 短元音 + 鼻音结尾 m / n / ng：读第 5 调，升调，拉丁拼音常写 ǎ。本篇例子：ฉัน chǎn、ผม phǒm、ฝน fǒn、ถุง thǔng。
- 高辅音 + 长元音，或高辅音 + 长元音 + 鼻音结尾：多读第 5 调，升调，拉丁拼音常写 ǎ。本篇例子：ฐาน thǎan、ศาลา sǎa-laa。
- 高辅音 + p / t / k 这类收尾音：属于死音节，读第 2 调，低调，拉丁拼音常写 à。本篇例子：ขวด khùat。

记忆句：高辅音没有声调符号时，活音节多读升调，死音节多读低调。

### 2. 高辅音加声调符号

- ่，泰语名字是 ไม้เอก。高辅音加这个符号，读第 2 调：低调，拉丁拼音常写 à。本篇例子：ไข่，khài。
- ้，泰语名字是 ไม้โท。高辅音加这个符号，读第 3 调：降调，拉丁拼音常写 â。本篇例子：ห้า，hâa。

本篇先重点记这两个：่ 让高辅音读低调，้ 让高辅音读降调。

### 3. 看 ฉัน 的规则

ฉัน 上面的 ั 不是声调符号，它是短元音 a。

ฉัน | chǎn | 我

拆开看：ฉ 是高辅音，ั 是短 a，น 是 n 结尾。n 结尾让它成为活音节，所以没有声调符号时读第 5 调：升调。

## 高辅音记忆句

### 1. 高辅音 ข

中文意思：鸡蛋
泰语：ไข่
拉丁拼音读音：khài
简单日常泰语例句：ผมกินไข่ครับ
> 例句拆解：ผม (phǒm)＝我（男性用）｜กิน (gin)＝吃｜ไข่ (khài)＝鸡蛋｜ครับ (khráp)＝男性礼貌结尾
> 发音规则提示：ไข่ 读 khài。原因：辅音类别=高辅音 ข；声调符号=ไม้เอก ่；规则结果=高辅音 + ไม้เอก，读第 2 调低调。句末 ครับ | khráp 是男性礼貌结尾，末尾轻轻收在 p。

中文句意：我吃鸡蛋。

### 2. 高辅音 ฃ

中文意思：旧字 ฃ，只用于认识字母；瓶子的现代常用写法是 ขวด
泰语：ขวด
拉丁拼音读音：khùat
简单日常泰语例句：ขวดอยู่ที่นี่
> 例句拆解：ขวด (khùat)＝瓶子｜อยู่ (yùu)＝在｜ที่นี่ (thîi-nîi)＝这里
> 发音规则提示：ขวด 读 khùat。原因：辅音类别=高辅音 ข；声调符号=无；音节类型=末尾 ด 是 t 收尾，属于死音节；规则结果=高辅音 + 无声调符号 + 死音节，读第 2 调低调，末尾轻轻收住。

中文句意：瓶子在这里。

### 3. 高辅音 ฉ

中文意思：我
泰语：ฉัน
拉丁拼音读音：chǎn
简单日常泰语例句：ฉันสบายดี
> 例句拆解：ฉัน (chǎn)＝我｜สบายดี (sà-baai dii)＝很好 / 状态好
> 发音规则提示：ฉัน 读 chǎn。原因：辅音类别=高辅音 ฉ；声调符号=无，ั 是短元音 a；音节类型=น 是 n 鼻音结尾，属于活音节；规则结果=高辅音 + 无声调符号 + 活音节，读第 5 调升调。สบายดี 里的 สะ 是高辅音 ส + 短死音节，读第 2 调低调 sà。

中文句意：我很好。

### 4. 高辅音 ฐ

中文意思：基础
泰语：ฐาน
拉丁拼音读音：thǎan
简单日常泰语例句：ฐานนี้ดี
> 例句拆解：ฐาน (thǎan)＝基础｜นี้ (níi)＝这个｜ดี (dii)＝好
> 发音规则提示：ฐาน 读 thǎan。原因：辅音类别=高辅音 ฐ；声调符号=无；音节类型=长元音 aa + น 鼻音结尾，属于活音节；规则结果=高辅音 + 无声调符号 + 活音节，读第 5 调升调。

中文句意：这个基础很好。

### 5. 高辅音 ถ

中文意思：袋子
泰语：ถุง
拉丁拼音读音：thǔng
简单日常泰语例句：ถุงนี้ของผม
> 例句拆解：ถุง (thǔng)＝袋子｜นี้ (níi)＝这个｜ของ (khǎawng)＝属于 / 的｜ผม (phǒm)＝我（男性用）
> 发音规则提示：ถุง 读 thǔng。原因：辅音类别=高辅音 ถ；声调符号=无；音节类型=ง 是 ng 鼻音结尾，属于活音节；规则结果=高辅音 + 无声调符号 + 活音节，读第 5 调升调。ของ 和 ผม 也按高辅音 + 活音节读升调。

中文句意：这个袋子是我的。

### 6. 高辅音 ผ

中文意思：我（男性用）
泰语：ผม
拉丁拼音读音：phǒm

## 复习笔记

- 先背类别：中辅音 9 个、高辅音 11 个、低辅音 24 个。
- 高辅音句子继续用来记：ข ฃ ฉ ฐ ถ ผ ฝ ศ ษ ส ห。
- 看见一个音节时，不要只看拼音声调；要回到“辅音类别 + 声调符号 + 活音节 / 死音节”去判断为什么这样读。
- ฃ 是旧字，本次只作为字母表记忆内容保留；实际“瓶子”用现代常用写法 ขวด | khùat。
